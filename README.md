# Simple Weather Frontend

## Quick start

1. Open `src/config.js`
2. Set your backend URL from Render:
   ```js
   backendBaseUrl: "https://YOUR-SERVICE.onrender.com"
   ```
3. Open `index.html` in a browser

## Notes

- This frontend calls your backend microservice, not OpenWeather directly.
- If you see fetch errors from a local file, serve the folder with a simple local server.
